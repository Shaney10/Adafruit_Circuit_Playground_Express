# Circuit Playground Express NeoPixel Scroller

A modular PlatformIO project driving the 10 onboard RGB NeoPixels on the Adafruit Circuit Playground Express.

## Hardware Information
- **MCU:** ATSAMD21G18 (ARM Cortex-M0+, 32-bit)
- **Onboard Pixels:** 10x WS2812B NeoPixels connected internally to **GPIO Pin 8**.

## How to Build and Flash in VS Code

1. Plug your Circuit Playground Express into your PC using a USB cable.
2. Open this folder in VS Code with PlatformIO installed.
3. Build project: Press `Ctrl+Alt+B` (or click checkmark on status bar).
4. Upload code: Press `Ctrl+Alt+U` (or click right arrow on status bar).
5. Open Serial Monitor: Click the plug icon on the bottom bar at 115200 baud.
